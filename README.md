# Personal Automation Dashboard

A Python-based collection of useful automation tools for everyday file and system management.

## Features

### Added

* ✓ Folder size calculator
* ✓ Folder and file counter
* ✓ File categorization
* ✓ File organization planning
* ✓ File size comparison
* ✓ File hashing
* ✓ Duplicate file finder using size and hash comparison
